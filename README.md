# 🌦️ WeatherSphere

**WeatherSphere** is a simple and responsive weather app built with React and Tailwind CSS. It displays real-time weather updates, air quality, and alerts using the OpenWeatherMap API.

## ✨ Features

- 🌍 Search by city or use your current location  
- 🌡️ Shows temperature, humidity, wind, and weather condition  
- 🕒 5-hour weather forecast  
- 🏞️ Air Quality Index (AQI)  
- 🚨 Weather alerts (if any)  
- 🍽️ Weather-based suggestions (like outdoor planner, recipes, weather tips)
- 📱 Fully responsive UI  

## 🛠️ Tech Stack

- **React JS** – Frontend framework  
- **Tailwind CSS** – Styling  
- **OpenWeatherMap API** – Weather and AQI data  
- **Geolocation API** – Get user’s current location  
- **Netlify** – Hosting & deployment  

## 🎯 Purpose

To practice React, API integration, and create a real-time weather app for learning and personal use.

## 🚀 Deployment

- Hosted on **Netlify**
- Add your API key in Netlify’s **Environment Variables** under site settings.

## 🛠️ How to Run Locally

1. Clone the repo  
   `git clone https://github.com/oviya5522/weatherapp.git`

2. Navigate into the project folder  
   `cd weatherapp`

3. Install dependencies  
   `npm install`

4. Add `.env` file:
   ```env
   REACT_APP_WEATHER_API_KEY=your_api_key

5. Start the development server
   `npm start`
